# Social Media User Analysis

## Overview

This project explores patterns in social media usage across different generations using a dataset containing over 1 million user records. The analysis focuses on Instagram usage and examines whether usage patterns differ between generations and whether user lifestyle characteristics may be associated with social media usage.

## Questions

* Which generations spend the most time on Instagram?
* What factors may be associated with higher Instagram usage?
* Do different Instagram features show different usage patterns across generations?

## Tools

* Python
* Pandas
* NumPy
* SQLite / SQL
* Matplotlib
* Seaborn

## Analysis

Due to the size of the dataset, a random 10% sample was used for the analysis to improve processing and visualization performance.

The analysis includes:

* Data exploration and cleaning
* Generation-based comparisons
* Instagram feature usage analysis
* Examination of lifestyle characteristics
* Data visualization using bar charts, pie charts, and heatmaps

## Findings

The analysis did not identify a clear difference in Instagram feature usage between generations. Lifestyle variables examined in the dataset also did not show strong relationships with Instagram usage.

These results suggest that the variables available in this dataset may not fully explain differences in social media usage. Other factors, such as social environment or external influences, could be explored in future analysis.

## Note

This project is intended as an exploratory data analysis exercise and does not establish causal relationships between social media usage and user characteristics.
